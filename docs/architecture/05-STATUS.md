### ۲. فایل CI در مخزن نیست

`.github/workflows/ci.yml` آماده و **اعتبارسنجی‌شده** است، اما:

```
! [remote rejected] ... (refusing to allow a GitHub App to create or update
  workflow `.github/workflows/ci.yml` without `workflows` permission)
```

توکن این نشست اجازهٔ افزودن فایل workflow را ندارد.
**راه‌حل:** فایل روی workspace هست؛ می‌توانید دستی کامیت کنید یا مجوز `workflows` را به اپ بدهید.
