# فلوهای محصول منشیم

- `monshim-flows.html` — سند تصویری و تعاملی فلوها (فارسی، RTL، بدون وابستگی خارجی).
- `monshim-flows-spec.json` — همان داده به شکل ساخت‌یافته برای ابزارهای دیگر.

سند شامل ۱۶ فلو، مرحله‌های هر فلو همراه با وضعیت رزرو، قواعد وضعیت،
و فهرست اصلاح‌های این دور است.

بازتولید:

```bash
python3 build-tmp/gen_v4.py   # داده در build-tmp/flows_data.py
```

> سند از روی کد همین مخزن ساخته شده است؛ اگر فلوها تغییر کرد، `flows_data.py`
> را به‌روز کنید و دوباره اجرا کنید.
