# فلوهای محصول منشیم

- `monshim-flows.html` — سند تصویری و تعاملی فلوها (فارسی، RTL، بدون وابستگی خارجی).
- `monshim-flows-spec.json` — همان داده به شکل ساخت‌یافته برای ابزارهای دیگر.

سند شامل ۱۶ فلو، مرحله‌های هر فلو همراه با وضعیت رزرو، قواعد وضعیت،
و فهرست اصلاح‌های این دور است.

## بازتولید

```bash
cd docs/flows
python3 generate.py
```

دادهٔ فلوها در `flows_data.py` است؛ برای تغییر متن یا افزودن مرحله، همان فایل را
به‌روز کنید. خروجی در ریشهٔ مخزن به نام `monshim-flows-final.html` و
`monshim-flows-spec.json` ساخته می‌شود؛ سپس نسخهٔ داخل `docs/flows` را جای‌گزین کنید.
