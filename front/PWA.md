# PWA منشیم

## معماری و تنظیمات

فرانت از Next.js 16 App Router و React 19 استفاده می‌کند. `app/layout.tsx` متادیتای iOS و viewport را اضافه می‌کند و `app/manifest.ts` مانیفست است. مدیر نصب در ریشه در همه layoutها بدون وابستگی به نقش یا نشست نصب شده؛ رابط Radix در زمان نیاز lazy-load می‌شود. `lib/pwa/config.ts` زمان نمایش (۵ ثانیه)، فاصله پس از بستن (۷ روز)، متن‌ها و سیاست worker را نگه می‌دارد؛ `lib/pwa/platform.ts` تشخیص و فهرست مسیرهای مجاز نمایش را پیاده می‌کند.

برای جلوگیری از قطع جریان کار، نمایش خودکار به صفحه‌های عمومی منتخب، `/panel/home` و `/dashboard` محدود است؛ در صفحه ورود، پروفایل عمومی، رزرو، پرداخت و سایر مسیرهای عملیاتی ظاهر نمی‌شود. هنگام باز بودن دیالوگ دیگر، فوکوس روی ورودی یا پنهان بودن تب نمایش را به تعویق نمی‌اندازد بلکه در آن فرصت نمایش را حذف می‌کند. نمایش یک بار در طول عمر صفحه و بعد از رد یا بستن تا ۷ روز سرکوب می‌شود؛ اگر storage در دسترس نباشد فقط محدودیت حافظه همان صفحه برقرار است. داده نشست در این کلید ذخیره نمی‌شود.

دکمه native فقط پس از دریافت `beforeinstallprompt` نشان داده می‌شود. iOS از راهنمای دستی استفاده می‌کند؛ در Chrome قدیمی iOS و مرورگرهای ناشناخته راهنمای Safari نشان داده می‌شود. Safari مک نسخه ۱۷ به بعد راهنمای Dock دارد. تشخیص iPad با حالت دسکتاپ از touch و platform هم استفاده می‌کند. رویداد `appinstalled` و تغییر display-mode در همان اجرا رابط را پنهان می‌کنند. هیچ استاندارد فراگیری برای دانستن نصب بودن اپ در تب عادی Safari یا پس از بازشدن مجدد مرورگر وجود ندارد؛ نصب از مرورگر یا دستگاه دیگر قابل تشخیص قطعی نیست و ممکن است راهنمای دستی دوباره دیده شود. نصب، باز شدن خودکار همه لینک‌ها در اپ یا وجود پرامپت native تضمین‌شده نیست و به مرورگر، سیستم‌عامل و تنظیمات آن بستگی دارد.

## امنیت، آفلاین و انتشار

- `app/sw.js/route.ts` یک worker در ریشه سرو می‌کند. در build محصول روی HTTPS یا localhost ثبت می‌شود؛ در dev ثبت نمی‌شود. پس از نصب worker فقط `/pwa/offline.html` و `/pwa/icon-192.png` با درخواست بدون کوکی از شبکه دریافت و ذخیره می‌شوند. هیچ کش runtime وجود ندارد: API، RSC، HTML صفحه‌ها، دارایی‌های Next، آپلودها، درخواست‌های غیر GET و cross-origin به شبکه سپرده می‌شوند. navigation فقط در صورت خطای شبکه (نه پاسخ ۴xx/۵xx) به صفحه عمومی آفلاین می‌رسد. درخواست‌های client-side و عملیات تراکنشی offline پشتیبانی نمی‌شوند و نباید خودکار تکرار شوند.
- worker جدید منتظر بسته‌شدن تمام کلاینت‌های نسخه قبلی می‌ماند؛ `skipWaiting` و reload اجباری ندارد. در فعال‌سازی تنها کش‌های قدیمی با پیشوند `monshiim-pwa-` حذف می‌شوند. هنگام هر تغییر در محتوای precache یا سیاست worker، `workerPolicy.cacheName` را در `lib/pwa/config.ts` به نسخه جدید افزایش دهید؛ deploy منابع precache و worker باید هم‌زمان و بدون redirect انجام شود. cache قدیمی تا فعال‌شدن نسخه جدید حفظ می‌شود.
- دارایی‌های آیکون از `public/logo/logo.png` تولید شده‌اند؛ آیکون maskable با فضای امن و پس‌زمینه روشن ساخته شده است. favicon قبلی `app/favicon.ico` حفظ شده است.
- دامنه canonical باید HTTPS معتبر، manifest و `/sw.js` را از همان origin و بدون redirect یا auth ارائه دهد؛ CDN و reverse proxy باید هدر `Cache-Control: no-cache, no-store` برای `/sw.js` و MIME جاوااسکریپت را حفظ کنند و روت‌های `/pwa/*` و `/manifest.webmanifest` را عبور دهند. CDN نباید پاسخ HTML خصوصی یا API را public cache کند. HTTPS، پروکسی API و کوکی‌های نشست و بازگشت از درگاه باید روی محیط واقعی تأیید شوند. اگر CSP سمت زیرساخت اضافه شود، `worker-src 'self'` و منابع لازم مجاز باشند.
- برای نصب و deep link یک origin canonical لازم است؛ مرورگر تصمیم می‌گیرد لینک داخلی در اپ نصب‌شده باز شود یا مرورگر. `start_url` برابر `/` است و مسیرهای مستقیم و callback احراز هویت دست‌نخورده‌اند. پس از استقرار، نسخه‌های Safari و دیگر مرورگرهای هدف، آیکون‌ها، standalone، پرداخت واقعی، بازگشت از درگاه و ورود/OTP را با دستگاه و حساب آزمایشی تأیید کنید.

## آزمون

```sh
pnpm exec tsc --noEmit
pnpm build
node --test lib/pwa/platform.test.ts
# بعد از راه‌اندازی build محصول با next start:
PWA_TEST_ORIGIN=http://localhost:3000 node --test tests/pwa/worker.test.mjs
pnpm test:session
```

آزمون worker آن را در محیط شبیه‌سازی‌شده اجرا می‌کند و جایگزین Application tab، Lighthouse، تست مرورگر واقعی، سنجش performance و تراکنش‌های واقعی نیست. برای هر انتشار، نصب Android Chrome، Windows Chrome/Edge، macOS Chrome/Edge/Safari، iPhone/iPad Safari/Chrome، offline، به‌روزرسانی worker با چند تب، عدم ذخیره داده حساس، بازگشت پرداخت و Deep Link را جداگانه بررسی کنید.
